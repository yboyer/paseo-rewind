paseo-rewind adds the ↑ shortcut to Paseo's empty message field on web and desktop.

A dialog asks you to cancel with Esc or confirm. The plugin uses Paseo's native Rewind action to return to the latest user message in the selected conversation. Files are also restored when the agent supports it. With Codex, only the conversation is restored; the dialog explains that file changes are kept.

The plugin creates no backups or commits. It uses Paseo's existing interface buttons, so interface updates may require changes to the plugin. The shortcut does not trigger when modifier keys are held, the message field is non-empty, or another dialog is open.

Requires Paseo 0.12 or 0.13 and an agent that supports Rewind. The plugin is inactive in the native iOS and Android apps.
